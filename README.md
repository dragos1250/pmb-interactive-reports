## 📋 About The Project

**PMB Smart Reports** is a frontend web application developed to digitalize and streamline the reporting of urban issues (such as potholes, broken public lighting, or illegal dumping) within Bucharest. 

To maintain the integrity of the platform and prevent spam or misinformation, the application follows a strict data-flow architecture: **users do not place pins directly on the map.** Instead, the system acts as a secure communication channel where citizens submit detailed reports, and the City Hall administration reviews, validates, and officially maps the confirmed issues.

### ✨ Key Features

* 📝 **Intuitive Reporting Form:** A seamless, user-friendly interface for citizens to submit urban issues with necessary details.
* 🛡️ **Admin Validation Protocol:** Built-in logic ensuring that the interactive map remains clean and authoritative. Only issues explicitly verified and approved by the local administration are rendered on the public map.
* 🗺️ **Interactive Civic Map:** Dynamic rendering of validated pins, giving the community a transparent view of acknowledged urban issues.
* 🤝 **Agile & Pair Programming:** Co-developed in a collaborative environment using Agile methodologies and strict pair-programming practices, ensuring clean, maintainable, and reviewed code.
